# Academic PDF Renamer - Quick Start Guide

**Tired of PDFs with cryptic names like `3687052.pdf` or `AUTHOR_NAME_UNIVERSITY.pdf`?**

This script automatically extracts the **actual paper title** from your academic PDFs and renames them to something meaningful and searchable.

## 📖 Features

- ✅ **Extracts real titles** - Not just author names or random numbers
- ✅ **Smart filtering** - Skips author names, affiliations, URLs, dates, metadata
- ✅ **Format support** - Handles ACM, IEEE, and other academic paper formats
- ✅ **Intelligent scoring** - Uses multiple strategies to find the most likely title
- ✅ **Safe operation** - Won't rename files that already have good names
- ✅ **Conflict handling** - Automatically handles duplicate titles

## 🚀 Quick Start

### Step 1: Install PyPDF2
```bash
pip3 install PyPDF2
```

### Step 2: Move the script to your papers folder
Copy `rename_papers.py` into the folder containing your PDF files.

### Step 3: Run it!
```bash
cd /path/to/your/papers/folder
python3 rename_papers.py
```

That's it! The script will automatically rename all PDFs in that folder.

## 🔧 Advanced Usage

If you want to process a different folder without moving the script:

1. Open `rename_papers_improved.py`
2. Change line 29: `FOLDER_PATH = "."`
3. Change it to your folder path: `FOLDER_PATH = "/path/to/papers"`
4. Run the script from anywhere

## 💡 Tips

- The script skips files that already have descriptive names (>50 characters)
- It won't modify the original files if it can't extract a title
- If two papers have the same title, it adds `_1`, `_2`, etc.
- Maximum filename length is 120 characters


## ❓ Troubleshooting

**"command not found: python3"**  
Try `python rename_papers_improved.py` instead

**"No module named PyPDF2"**  
Run: `pip3 install PyPDF2` (or `pip install PyPDF2`)

**"No PDF files found"**  
Make sure you're in the right folder or check the FOLDER_PATH setting
